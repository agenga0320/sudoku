# AI數獨教練 Sudoku

簡潔的 Android 數獨遊戲，支援難度分級，也可以匯入自己的題目。以 Kotlin 撰寫，只使用 Android 內建框架，沒有第三方相依套件；AI 解題思路直接以 HTTP 呼叫各家 AI 服務的 API。

## 功能

- **難度分級**：簡單、中等、困難（約 40／32／26 個提示數字），每一題都保證只有唯一解。
- **匯入題目**：輸入報紙、書上或其他來源的題目來玩，並附上可複製的 AI 提示詞，把題目照片轉成匯入格式。
- **筆記**：在空格中標記候選數字；同行、同列或同宮格已經有某個數字時，該數字的筆記不會被寫入（避免誤觸）；填入數字後，會自動清掉同行、同列、同宮格裡的相同筆記。
- **鎖定數字模式**：開啟「鎖定」後先選一個數字，之後每點一個空格就直接填入該數字，按住在盤面上滑動則會連續填入經過的空格，盤面上相同的數字會同時標示出來。也可以直接點盤面上題目給的數字，把選定的數字換成它。點自己填的數字時，筆記模式下同樣是把選定的數字換成它；非筆記模式則是用選定的數字取代該格。再點一次同一個數字按鈕可取消選取；搭配筆記模式則是在空格中標記該數字。
- **標示相同數字**：選到某個數字時（選取含該數字的格子，或在鎖定模式選定數字），盤面上相同的數字會標示出來，筆記裡的該數字也會變成藍色粗體。
- **AI 解題思路**：卡關時按「提示」，由 AI 教你下一步該怎麼想，不會直接說出答案。可選 Claude、ChatGPT、Gemini、Grok、DeepSeek 或 Mistral，需要自己在該服務的 API 金鑰（見下方）。
- **復原、重做、清除**：復原之後可以用「重做」把步驟加回來；復原後若填了新的數字或筆記，就不能再重做。
- **不提示對錯**：填錯的數字不會被標示，也不計算錯誤次數；只有在盤面填滿但仍有錯時，才會提醒再檢查。
- **檢查更新**：每次開啟 app 時會到 GitHub Releases 查詢最新版本，有新版就詢問是否下載；離線時不會有任何提示。
- **計時**
- **自動存檔**：離開 app 後再回來可以接續上一局。
- **深色模式**：跟隨系統設定。

## 匯入題目

按下右上角的「匯入」，輸入 9 排數字，每排 9 個，空格用 `0` 表示：

```
530070000
600195000
098000060
800060003
400803001
700020006
060000280
000419005
000080079
```

數字以外的字元（空白、逗號、換行）會被忽略，只要總共剛好 81 個數字即可。以下情況會顯示原因，不會開始遊戲：

- 數字不是 81 個
- 同一行、列或九宮格內有重複的數字
- 題目無解，或有不只一組解

### 用 AI 把照片轉成匯入格式

匯入畫面中的「複製 AI 提示詞」會把下面這段提示詞複製到剪貼簿。把它連同題目照片一起傳給 AI（例如 Claude、ChatGPT），再把 AI 的回覆貼回匯入畫面。

```
請辨識這張圖片中的數獨題目，並嚴格依照下列格式輸出：

1. 總共 9 排，每排剛好 9 個數字，由上到下、由左到右對應盤面。
2. 空白的格子用數字 0 表示。
3. 同一排的數字之間不要有空格、逗號或任何其他符號。
4. 只輸出這 9 排數字，不要加上任何說明、標題或程式碼區塊。
5. 輸出前請逐排核對：每排是否剛好 9 個數字、位置是否與圖片一致。看不清楚的格子請填 0，不要猜測。

輸出範例：
530070000
600195000
098000060
800060003
400803001
700020006
060000280
000419005
000080079
```

AI 辨識可能出錯。如果匯入時顯示無解或有多組解，通常是某個數字認錯或漏掉，請對照原題修正。

## AI 解題思路

按右上角的「提示」，app 會把目前的盤面和每個空格的候選數字送給玩家選的 AI 服務，請它找出下一個能靠邏輯確定的格子，並分三層說明：

1. **看哪裡**：只指出該看的橫排、直行或宮。
2. **怎麼想**：說明要用的觀察角度或技巧。
3. **推理過程**：一步步帶到可以確定那一格，但最後一步留給玩家。

按「再多一點」才會顯示下一層。AI 回覆時會另外附上它推出的格子和數字（不顯示），app 會用正確解答核對，不對就重問一次，兩次都不對就不顯示提示。盤面上有填錯的數字時，也可能因此拿不到提示。

### AI 服務與金鑰

提示功能使用玩家自己的 API 金鑰，費用從玩家在該服務的帳戶扣除。第一次按「提示」會開啟設定畫面，之後長按「提示」可以再回來修改。

| 服務 | 預設模型 | 取得金鑰 |
| --- | --- | --- |
| Claude (Anthropic) | `claude-opus-5-5` | <https://platform.claude.com/> |
| ChatGPT (OpenAI) | `gpt-5.6` | <https://platform.openai.com/api-keys> |
| Gemini (Google) | `gemini-flash-latest` | <https://aistudio.google.com/apikey> |
| Grok (xAI) | `grok-4.7` | <https://console.x.ai/> |
| DeepSeek | `deepseek-v4-pro` | <https://platform.deepseek.com/api_keys> |
| Mistral | `mistral-large-latest` | <https://console.mistral.ai/api-keys> |

1. 選擇 AI 服務，按「開啟取得金鑰的網頁」，註冊或登入後建立 API 金鑰並複製。多數服務的金鑰只會完整顯示一次。
2. 多數服務要先儲值才能用。聊天用的訂閱（Claude Pro、ChatGPT Plus 等）不包含 API 額度。
3. 把金鑰貼上後儲存。每個服務各存一把金鑰和模型名稱；清空金鑰後儲存即刪除。

各家的模型名稱經常更換，預設值可能已經過期。貼上金鑰後按「從清單選擇模型」，app 會向該服務查詢這把金鑰可用的模型，從中選一個即可。推理能力較弱的模型比較常推錯，會更常遇到拿不到可靠提示的情況。

金鑰只存在手機上的 app 設定裡，只會傳給玩家選的那個服務。新增服務只要在 `Coach.kt` 的 `Provider` 加一行（Claude 以外都走 OpenAI 相容的 chat completions 協定）。

## 系統需求

- Android 8.0（API 26）以上

## 建置

需要 JDK 17 以上與 Android SDK（platform 34）。用 Android Studio 開啟專案，或在命令列執行：

```bash
./gradlew assembleDebug
```

```bash
./gradlew testDebugUnitTest
```

Windows 請改用 `gradlew.bat`。

### Release 版本

Release APK 需要簽章。先建立金鑰庫：

```bash
keytool -genkeypair -keystore release.jks -storetype PKCS12 -alias sudoku -keyalg RSA -keysize 2048 -validity 10000
```

接著在專案根目錄建立 `keystore.properties`：

```properties
storeFile=release.jks
storePassword=你的密碼
keyAlias=sudoku
keyPassword=你的密碼
```

然後建置：

```bash
./gradlew assembleRelease
```

產出的檔案在 `app/build/outputs/apk/release/Sudoku-v<版本>-release.apk`。

`release.jks` 與 `keystore.properties` 已列在 `.gitignore`，請勿提交到版本控制，並自行妥善備份：遺失金鑰庫就無法再以同一個簽章發布更新。

## 專案結構

| 檔案 | 內容 |
| --- | --- |
| `Sudoku.kt` | 題目產生、解題、唯一解檢查、匯入解析 |
| `Coach.kt` | AI 解題思路：AI 服務清單、組成提示詞、以 HTTP 呼叫 API、核對 AI 的推理 |
| `Game.kt` | 一局遊戲的狀態：填數、筆記、復原、存檔 |
| `BoardView.kt` | 繪製盤面與處理觸控的自訂 View |
| `MainActivity.kt` | 主畫面、難度選擇、鎖定數字模式與匯入對話框 |
| `SudokuTest.kt` | 單元測試 |

原始碼位於 `app/src/main/java/com/example/sudoku/`。
